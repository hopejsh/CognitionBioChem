CognitionBioChem

Structural pharmacology workbench — validation, provenance, and real predictor-output analysis

Structure prediction is real; binding affinity is not calibrated and no free energy is emitted.

The result this workbench was built to report is negative

What this workbench does, and does not do

It does

  • Validate every chemical structure with RDKit — parsing, molecular formula, InChIKey, and stereochemistry completeness.
  • Compute real peptide properties from sequence: molecular weight, net charge at pH 7.4, isoelectric point, and Kyte–Doolittle hydropathy.
  • Check every stated ΔG/Kd pair for thermodynamic consistency against ΔG = RT·ln(Kd).
  • Parse genuine predictor output — AlphaFold Server, AlphaFold DB, or Boltz — and display the real per-residue pLDDT, the real PAE matrix, and the real coordinates.
  • Flag designs whose target is in a compartment the molecule cannot reach.
  • Attach a provenance record to every value, so nothing can be displayed without a stated origin.

It does not

  • Run AlphaFold3. Its weights are request-only, non-commercial, and Linux/CUDA-bound; Boltz-2 v2.2.1 (MIT code and weights) runs locally instead and produced every predicted structure under runs/. runs/ also holds 32 RCSB crystal depositions — experimental ground truth for studies #6 and #7, produced by no predictor.
  • Display a binding free energy or dissociation constant as a result. No docking, MM-GBSA or FEP calculation exists here, and structure predictors do not output free energies in any case. Boltz-2's affinity head emits pooled potency on a log scale, which is never converted to kcal/mol.
  • Predict ADMET for a molecule outside ADMET-AI's applicability domain. Those are refused with a stated reason rather than given a number.
  • Claim any affiliation with Google DeepMind or the AlphaFold team.

How to get a real prediction

  1. Pick a candidate under Candidate sequences and copy its FASTA. Sequences that fail validation cannot be copied — they are not submittable.
  2. Run it through a predictor you have the right to use. Note that the AlphaFold Server terms prohibit automated use for predicting protein–ligand or protein–peptide binding; for an automated pipeline use a permissively licensed model such as Boltz-2, Chai-1, Protenix, or OpenFold3 — noting that only Boltz and AlphaFold confidence files are parsed here; other formats load as structure only.
  3. Bring the returned .cif and confidence JSON back to Structures and load them. Everything shown there is then read from your files.

A single peptide chain predicted alone has no interface, so ipTM and interface PAE are undefined for it. To evaluate a binder, predict the peptide together with its receptor chain.

The pre-registered slate

Each study froze a question, a primary metric, a decision threshold and an analysis plan under a content hash before any data was seen. What follows is assembled by platform/build_slate.py from those plans and from the study artefacts — no verdict, threshold or p-value on this page is typed by hand.

What this supports, and what it cannot

    Data-integrity gate

    Produced by platform/validate.py, which exits non-zero when any record fails. Every count below is reproducible from a clean checkout.

    Natural product structures

    Each structure is parsed with RDKit. A compound whose stored SMILES fails to parse, or encodes a different molecule than its name, is shown as unverified rather than rendered with computed properties.

    Candidate sequences

    These are chimeric peptides: published natural motifs, motif-like segments with no identifiable natural source, and one de novo amphipathic helix, concatenated head to tail with GGGGS linkers. No generative model, sequence optimisation or structure-based design software was used. Per-segment attribution is in motif_provenance. Properties shown are computed from the sequence.

    Structures computed in this repository

    Every entry below is a real model held under runs/ or data/alphafold_db/. Selecting one loads its actual coordinate file — the pLDDT curve, the PAE matrix and the Cα geometry check are all read from that file, the same way a file you drop in yourself would be.

    Or load your own predictor output

    Drop a coordinate file and, optionally, its confidence JSON. Everything rendered below is read from these files. Nothing is synthesized.

    Drop files here or

    AlphaFold Server: *_model_*.cif + *_full_data_*.json + *_summary_confidences_*.json
    AlphaFold DB: AF-<ACC>-F1-model_v*.cif + *predicted_aligned_error*.json
    Boltz: *_model_*.cif + confidence_*.json (pae_*.npz is not readable in a browser — the PAE panel stays empty)

    Goes to the network. The same entry is already in the gallery above, served from this repository; this button exists to show the two agree.

    Geometry check

    Consecutive Cα atoms in a real polypeptide sit 3.80 Å apart with very little variance. This check is what distinguishes genuine coordinates from a parametric curve.

    How to cite this workbench

    Read from CITATION.cff at build time — the same file the registries read, so the page cannot fall out of step with them.

    Provenance model

    Every scientific value in this workbench carries a status. The UI cannot render a number whose status is placeholder or not_computed — those states produce a label, never a figure.

    StatusMeaningRequired metadata
    computed Calculated in this repositorymethod + software version
    predicted Output of a modelmodel name + version
    database Retrieved from a public databaseaccession
    literature Taken from a publicationDOI or PMID
    measured Wet-lab measurementcitation
    placeholder Illustrative only — never a resulta note saying so
    not computed Honestly absentwhy it is absent

    Fabricated values quarantined from the previous version

    An earlier version of this project displayed affinity, confidence and safety values as though they had been computed. No calculation produced them. They are preserved here rather than deleted, so the record of what was asserted is not lost.
